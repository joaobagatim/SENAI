## 🧪 Quality Assurance | Software Testing

Projetos voltados à aplicação de técnicas de teste e garantia de qualidade, com foco na identificação de falhas, validação de requisitos e confiabilidade do software.

### 01. Testes de Integração — Agendamento de Helicópteros

📂 [Acessar projeto](./QA/Trabalho-Assincrono-Teste-de-Integracao)

Projeto de testes de integração desenvolvido em Python, utilizando Pytest e SQLite para validar o fluxo de agendamento de helicópteros.

**Conceitos aplicados:**
- Testes automatizados de integração.
- Validação de regras de negócio.
- Verificação de conflitos de horário.
- Isolamento de dados com fixtures.
- Verificação de transações e persistência.
- Análise de cobertura de testes.

**Tecnologias:** `Python` `Pytest` `SQLite`

### 02. Testes de Regressão — E-commerce

📂 [Acessar projeto](./QA/AtividadeTesteRegressao_QualidadeTestesSoftware)

Atividade prática de qualidade de software voltada à aplicação de testes de regressão em funcionalidades de um sistema de e-commerce.

**Conceitos aplicados:**
- Testes de regressão.
- Validação de funcionalidades.
- Verificação de regras de negócio.
- Testes automatizados com Python.
- Prevenção de falhas após alterações no código.

**Tecnologias:** `Python` `Software Testing`

### 03. Testes Unitários — Carrinho de Compras

📂 [Acessar projeto](./QA/Trabalho-I-QA---Joao-Victor-Bagatim)

Implementação e validação de um componente de carrinho de compras, aplicando conceitos de qualidade de software com base na **ISO/IEC 25010**.

**Conceitos aplicados:**
- Testes unitários automatizados.
- Particionamento de equivalência.
- Análise de valores-limite.
- Validação de descontos e frete.
- Tratamento de entradas inválidas.
- Confiabilidade e adequação funcional.

**Tecnologias:** `Python` `Pytest`

## 🎯 Objetivos de aprendizado

Este repositório representa uma parte importante da minha formação técnica.

Por meio dessas atividades, busco desenvolver competências em:

- **Desenvolvimento:** lógica de programação, aplicações web, organização de código e boas práticas.
- **Qualidade de software:** criação de cenários de teste, validação de requisitos, automação e análise de falhas.
- **Resolução de problemas:** interpretação de requisitos, investigação de comportamentos e implementação de soluções.
- **Evolução contínua:** aprendizado de novas tecnologias, ferramentas e metodologias de desenvolvimento.

Acredito que compreender tanto a construção quanto a validação de software contribui para desenvolver soluções mais confiáveis, eficientes e sustentáveis.
